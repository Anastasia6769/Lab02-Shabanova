«ПР2. Ответы на контрольные вопросы»
1.double иногда хранит числа не точно,поэтому при вычислениях могут появляться ошибки.decimal хранит точные десятичные числа точнее,поэтому для денег лучше использовать его.
2.Если число выйдет за допустимые границы,может произойти переполнение.Например,если byte  будет больше 255 то значение может перейти в начало диапозона.
3.В С# компилятор сам определяет тип переменной во время компиляции.В Python тип определяется во время программы.
4.Всегда возвращает string то есть строку.Даже если пользователь ввел число,сначало оно будет строкой.
5.int.Parse выдаст ошибку если введены не цифры.int.TryParse ошибки не выдает, а просто возращает в false.
6.Это означает, что преобразовать значение в число не получилось.В переменную с out попадает значение 0 для int.
7.Например,когда пользователь сам вводит число с клавиатуры.Он может написать случайно буквы.Лучше использовать TryParse,потому что программа просто покажет,что ввод неправильный.
